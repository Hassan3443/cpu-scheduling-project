What do WT, TAT and RT mean?
WT, waiting time
Time a process spent ready but not running. Lower is better.
TAT, turnaround time
From arrival until the process finishes (waiting plus running).
RT, response time
From arrival until the process gets the CPU for the first time.
Context switch
The CPU changes from one process to a different one.
CPU utilisation
Share of the time span in which the CPU was busy, not idle.

How to use this simulator

It shows how a CPU decides which process runs next, and compares five scheduling methods on the same list of processes.

  1. Pick an example on the Setup tab, or press "Add a process" to build your own list.
  2. Edit the numbers. Arrives at is when the process shows up, Needs is how long it must run, Priority 1 is the most urgent.
  3. Set the time slice (quantum) for Round Robin. Each process runs at most this long before the next one gets a turn.
  4. Read "Result at a glance". It compares all five algorithms. The green number is the best in its column. Lower is better for wait, turnaround and response.
  5. Open the Timeline tab to see who ran when. Gray blocks marked IDLE mean the CPU had nothing to run. Press Replay to watch it again.
  6. Open Numbers, Verdict and All 5 algorithms for per-process details and a short written comparison.

Everything updates as you type. Nothing is sent anywhere; the page only remembers that you closed the welcome note. Time units are abstract (not seconds).
